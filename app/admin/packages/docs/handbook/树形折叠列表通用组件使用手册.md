# 树形折叠列表通用组件使用手册

## 一、用途

`CategoryTreeTable` 用于将 Bootstrap Table 已加载的扁平层级数据展示为可折叠树。组件只处理前端展示和交互，不请求接口、不限制业务字段，也不改变后端的删除、权限、统计等逻辑。

公共资源统一位于 `app/admin`：

| 内容 | 文件 |
| --- | --- |
| JavaScript 组件 | `public/app/admin/static/tree-table/tree-table.js` |
| 组件样式 | `public/app/admin/static/tree-table/tree-table.css` |

## 二、前置条件

1. 页面已经引入 jQuery 与 Bootstrap Table。
2. 后端列表返回父级在前、子级在后的扁平数据。
3. 每行至少包含唯一主键、父级 ID 与名称字段；层级字段可选。
4. 当前组件默认只展示顶级项，用户可逐级展开。

## 三、页面引入

在页面中先引入公共样式与脚本：

```html
<link rel="stylesheet" href="{$siteRoot}/app/admin/static/tree-table/tree-table.css">
<script src="{$siteRoot}/app/admin/static/tree-table/tree-table.js"></script>
```

静态 URL 通过 `/app/admin/static/` 映射到 `public/app/admin/static/`，与文件预览公共组件保持相同目录约定。

## 四、列表页接入

先完成 Bootstrap Table 初始化和 `Table.api.bindevent(table)`，再初始化组件：

```javascript
var table = $('#table');

table.bootstrapTable({
    columns: [[
        {checkbox: true},
        {field: 'id', title: 'ID'},
        {field: 'name', title: '类型名称', operate: false},
        {field: 'level', title: '层级', operate: false}
    ]]
});

Table.api.bindevent(table);

var categoryTreeTable = CategoryTreeTable.init(table, {
    idField: 'id',
    parentField: 'pid',
    levelField: 'level',
    nameField: 'name',
    toolbar: '#toolbar',
    defaultExpanded: false
});
```

`nameField` 必须与 Bootstrap Table 的名称列 `field` 一致。若当前列表使用的是后端预拼接缩进的 `name_show`，接入时应将该列改为原始名称字段（例如 `name`），由本组件统一处理缩进和展开箭头。

树形折叠列表不使用固定操作列，页面不要配置 `fixedColumns`、`fixedRightNumber`，操作列保持普通表格列。

## 五、配置项

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `idField` | `id` | 当前节点的唯一标识字段 |
| `parentField` | `pid` | 父级节点标识字段 |
| `levelField` | `level` | 层级字段配置项，保留用于兼容现有页面；缩进以 `parentField` 的实际父子关系计算 |
| `nameField` | `name` | 名称字段，同时也是名称列表列字段 |
| `toolbar` | `#toolbar` | 放置“展开全部、收起全部”按钮的容器 |
| `defaultExpanded` | `false` | 是否默认展开全部；本次课程分类场景使用 `false` |

## 六、交互与数据边界

1. 父级不存在的记录会按顶级项展示，避免脏数据导致记录不可见；循环关系中的循环节点也会作为顶级项显示，其后代仍需手动展开。
2. 有子级的节点会显示折叠图标；点击图标或名称区域均可展开、收起当前节点。展开一个节点只展示其直接子级；深层节点仍需逐级展开。
3. 表格刷新后，组件会重新按当前展开状态渲染；新增数据不会触发后端查询改造。
4. 组件仅隐藏或显示原表行，不修改 Bootstrap Table 数据，也不主动修改已勾选行。存在批量操作时，业务页面应自行确认是否需要清理被折叠行的选择状态。
5. 子级通过 26px 阶梯缩进及浅色层级引导线展示；叶子节点保留与折叠图标等宽的占位，保证同级名称对齐。
6. 名称文本会进行 HTML 转义后再写入单元格，避免分类名称包含 HTML 时直接执行。

## 七、实例方法

| 方法 | 说明 |
| --- | --- |
| `expandAll()` | 展开全部有子级的节点。 |
| `collapseAll()` | 收起全部节点。 |
| `expandNode(id)` | 展开指定父级；叶子节点或不存在的节点不处理。适用于新增子级后，在列表刷新完成时让新子级可见。 |
| `refresh()` | 按当前展开状态重新渲染表格。 |

新增子级保存成功后，业务页可先记录父级 ID，再在 Bootstrap Table 的 `post-body.bs.table` 事件中调用：

```javascript
categoryTreeTable.expandNode(parentId);
```

## 八、适用范围

课程类型、课程形式、素材类型等后台树形分类列表均可复用本组件。各业务页面只需保留自己的列表接口、按钮权限、删除前校验和业务列；无需新增通用后端接口。
